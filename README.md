# **MiniAlgo Compiler**

A mini compiler for the **MiniAlgo** programming language using **Flex** and **Bison**.


# **Overview**

This project implements the main stages of a compiler, from lexical and syntax analysis to semantic analysis and intermediate code generation.

### **Features**
- **Lexical and Syntax Analysis**
- **Semantic Analysis**
- **Symbol Table Management**
- **Quadruplet Generation**
- **Code Optimization**
- **Assembly Code Generation**
